# PINN-example-The forgetting curve
## How to Use This Repository
This repository contains beginner-friendly examples of Physics-Informed Neural Networks (PINNs). The notebook is designed to introduce a concept step by step, from defining a physical law to training a neural network that learns from it.
### Repository Structure

* `PINN_Forgetting_Curve_Example.ipynb`

  * A simple PINN example that models how memory fades over time using a differential equation.
  * Recommended starting point if you're new to PINNs.

* `assets/`

  * Images and visualizations used in the Medium blog posts.

### Running the Notebooks

1. Clone the repository:

```bash
git clone <repository-url>
cd <repository-name>
```

2. Install dependencies:

```bash
pip install torch numpy matplotlib scipy
```

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open any notebook and run the cells from top to bottom.

### What You'll Learn

* Neural Networks
* Automatic Differentiation
* Differential Equations
* Physics Loss Functions
* Initial and Boundary Conditions
* Physics-Informed Neural Networks (PINNs)

These examples focus on intuition and understanding rather than state-of-the-art implementations, making them suitable for students, beginners, and anyone curious about combining machine learning with scientific principles.
